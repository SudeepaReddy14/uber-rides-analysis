**Uber Rides Analysis — NYC April 2014**

**Project Overview**
Analyzed 564,516 Uber rides in NYC using Python, Pandas, Matplotlib and Seaborn to identify peak demand patterns and geographic hotspots.


**Key Findings**
Peak Hour:5 PM has highest ride demand (40K+ rides)
Busiest Day:Wednesday sees 110K+ rides
Trend:Demand steadily increased throughout April
Hotspot:Manhattan accounts for majority of pickups
